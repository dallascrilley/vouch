# What's Next — 2026-06-14

**Strategic track:** `finish`

**Project goal / north star:**

The AI Human Review Broker is a contract-first verification control plane for agent workflows. Operators and coding agents commission human (or simulated/MTurk) review via `npm run review`, receive structured verdict and feedback (`agent_next_action`), and gate releases through `npm run verify`. The repo dogfoods its own broker as CI/release gate. Phases 1–3 of `docs/planning/goalplan.md` are marked done with sandbox, simulated, and production paid MTurk proof; Phases 4–6 (operational hardening, provider generalization, full agent-autonomous loop) remain open.

## Product Strategy

- **Target Persona:** Platform engineers and agent operators who need external pass/fail verdicts on visual QA, rubric checks, and instruction-following tasks their agents cannot self-certify.
- **Job To Be Done:** Route uncertain agent output through privacy-gated human review and get a deterministic machine-readable next action without manual interpretation.
- **Core Value Path:** `npm run review --template … --question … --screenshot … --wait` → provider dispatch (sim/MTurk) → callback ingestion → `GET …/feedback` → exit code 0/1/2/3/4/5.
- **Activation Moment:** Review CLI returns JSON with `agent_next_action` and a matching exit code; agent can branch without reading HIT UI.
- **Current Friction:** Return-path proof is strong for pass (sandbox + prod + simulated) and offline for ambiguous/fail, but live Bux ambiguous regression is still optional; MTurk bridge lacks Phase 4 operational controls; no consolidated launch contract ties proof status to P0 criteria.
- **Feature Opportunity:** Pairwise tie-break micro-task for split/ambiguous worker signals before full consensus (see `docs/ideation/2026-06-09-surprise-me-ideation.md` #2). Deferred — finish track prioritizes ops hardening and proof consolidation first.
